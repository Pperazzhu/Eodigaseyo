# 어디가세요? (Eodigaseyo)

주변 차에 "어디가세요?"를 한 번 물어 **나와 같은 곳·같은 방향으로 가는 차가 몇 대인지** 알려주고, 그 답을 모아 목적지 주차장 혼잡·출발 시간·나갈 출구까지 안내하는 Pleos Connect 차량용 앱입니다.

> 현대자동차그룹 차량용 앱 개발 공모전 출품작

## APK 위치

- `apk/어디가세요_어디가세요_release.apk`

## 주요 기능

| 기능 | 내용 |
|---|---|
| ① 📣 다 같이 묻기 | 반경 500m 안의 가까운 차 최대 20대에 "어디가세요?"를 묻고 🎉 같은 곳 · ➡️ 같은 방향 · ↗️ 다른 방향 · 🙂 비공개로 모아 보여줘요. 레이더는 방향 8칸 × 거리 3칸만 표시해요. |
| 자동 답장 | 다른 차의 질문에는 설정대로 자동으로 답해요. 주행 중이거나 앱이 화면에 없을 때 받은 질문은 정차하면 한 번에 알려줘요. |
| ② 목적지 혼잡·주차장 대기 | 같은 곳 가는 차 합계로 혼잡과 주차장별 대기를 계산하고, 더 빠른 주차장으로 내장 내비 경로를 바꿔요. |
| ③ 출발 시간 추천 | 기어 P에서 지금/10분/30분/1시간 뒤 혼잡을 비교하고 알림을 맞춰요. |
| ④ 주차 기억·나갈 때 안내 | 도착 + P = 주차, D = 출차. 출구별 대기를 비교하고 추천 출구를 내비 경유지로 넣어요. |

주행 상태에 따라 화면이 바뀌어요.

- **주차·정차:** 전체 기능
- **신호 대기(D + 브레이크로 멈춤):** 큰 "다 같이 묻기"·"인사하기" 버튼 + 전체 화면은 목적지 주변 지도
- **주행 중:** 목적지·혼잡·주차장 대기를 큰 글씨로 + 주변 차 레이더(보기만)

## 실행 방법

### APK로 바로 설치

1. Pleos Connect 에뮬레이터를 켜요.
2. APK를 설치해요.
   ```bash
   adb install -r "apk/어디가세요_어디가세요_release.apk"
   ```
3. 화면 아래 독(Dock)에서 **어디가세요?** 아이콘을 눌러요. 내비 옆 분할 화면과 전체 화면을 모두 지원해요.

### 소스에서 빌드

1. 이 저장소를 Android Studio로 열고 Gradle Sync를 해요. Pleos SDK 저장소 설정은 `settings.gradle.kts`에 있어요.
2. 실행 대상을 Pleos Connect 에뮬레이터로 고르고 ▶ Run을 눌러요.

## 시연 방법 (필요한 설정)

1. **목적지 정하기:** 현대 내장 내비에서 목적지를 검색해 안내를 시작해요. 예: `한강공원 여의도1주차장`. 앱이 목적지를 자동으로 읽어요.
2. **처음 묻기:** "📣 다 같이 묻기"를 누르면 '내 목적지도 알려줄까요?'를 한 번 골라요. 목적지 알려주기는 기본 꺼짐이에요. 켜야 다른 차의 답도 보여요.
3. **기어·브레이크 바꾸기:** Pleos Virtual Console을 써요.
   ```bash
   adb forward tcp:8088 tcp:8088   # 에뮬레이터를 다시 켤 때마다
   ```
   브라우저에서 `http://127.0.0.1:8088`을 열고 Gear Selection(P/R/N/D)과 Brake Pedal을 바꿔요. 주행 속도는 Highway 화면의 ACCEL·BRAKE로 바꿔요.
4. **신호 대기 묻기:** D에서 브레이크를 밟고 멈추면 큰 버튼이 나와요.
   - 처음 P에 두면 차 속도 권한을 설명한 뒤 물어봐요. 시스템 창에는 '위치 정보'로 표시돼요.
   - 허용하지 않아도 브레이크를 1.5초 이상 밟고 있으면 동작해요.
5. **시연 버튼:** 에뮬레이터에서는 실제로 도착할 수 없어요. 앱 이름("어디가세요?")을 길게 누르면 `도착 시연`·`주행 시연` 버튼이 나타나요.

## 참고

- 다른 차는 지금 앱 안의 **가상 주변 차 60대**가 대신해요(몇 분마다 일부가 바뀌어요). 시연 숫자가 매번 같도록 고정된 시드를 써요.
- 주차장·출구 대기 시간과 요일·시간대 통계는 시연용 가정값이에요.
- 앱 안의 목적지 주변 지도는 여의도 한강공원 시연용 그림이에요. 실제 길 안내와 지도는 현대 내장 내비가 맡아요.
- 출발 알림 시연: "⏰ 알려주기" 버튼을 길게 누르면 15초 뒤에 알려줘요.
- 실제 서비스에서는 서버가 '같은 곳 / 같은 방향 / 다른 방향' 결과만 계산해 주고, 개별 목적지는 다른 차에 보내지 않아요.
- 같은 곳 가는 차가 5대 미만이면 숫자와 위치를 숨겨요.
- 주변 차가 3대 이상일 때만, 10분에 5번까지만 물을 수 있어요.
- 출시 빌드에서는 위치·목적지 로그를 남기지 않아요.
